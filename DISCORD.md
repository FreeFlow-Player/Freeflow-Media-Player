# FreeFlow on Discord

Join the FreeFlow community on Discord to chat with other users and contributors, ask questions, share feedback and follow development.

**[Join the FreeFlow Media Player server](https://discord.gg/amWCH8Gyqt)**

## What it's for

- **Getting help:** ask how to install, set up or use FreeFlow
- **Sharing feedback:** tell us what works, what doesn't and what you'd like to see
- **Following development:** see what's being worked on and what's coming next
- **Talking with contributors:** discuss ideas and get advice before opening a pull request
- **Meeting other users:** share tips, setups and screenshots

## Before you post

- **Be kind.** Our [Code of Conduct](CODE_OF_CONDUCT.md) applies on Discord as well as on GitHub.
- **Search first.** Your question may already be answered in the [README](README.md) or in existing [GitHub issues](https://github.com/freeflow-player/freeflow-player/issues).
- **Give details.** When asking for help, include your operating system, your FreeFlow version and what you expected to happen.
- **Don't share private information.** Never post passwords, tokens or personal data, and be careful with log files that contain file paths.

## Verification

Please be aware, our discord server may ask a randomly selected group of people to complete a Captcha. This is done via CaptchaBot, their privacy policy can be viewed at [iubenda.com](https://www.iubenda.com/privacy-policy/98954782/legal)

## Bugs and feature requests

Discord is great for quick questions and conversation, but chat history is easy to lose. For anything that needs tracking, please open a [GitHub issue](https://github.com/freeflow-player/freeflow-player/issues) so it doesn't get forgotten.

| Issue                 | Github | Discord|
| ----------------------| -------| -------|
| Bug Reports           | ✓      | ✕      |
| Feature Requests      | ✓      | ✓      |
| Security Vunrabilities| ✓      | ✕      |

## Security issues

Please **don't** report security vulnerabilities on Discord. Follow the private process in [SECURITY.md](SECURITY.md) instead.

## Reporting problems on the server

If someone is breaking the Code of Conduct, contact a moderator or admin through a direct message, or use the reporting route in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
